# Trabajo de campo-2026
# Forma de trabajo:
- Antes de empezar a trabajar en el proyecto debemos siempre hacer un git pull
- No hacer git merge , a cambio de eso debemos crear una rama nueva, subirla y luego hacer un pull request eligiendo la rama premaster (Premaster es en la rama que se va a trabajar , MAIN es sagrada)
- Crear issues y asignarlo a su hito correspondiente, Nomenclatura del issue: tipo:descripcion . Ejemplo : **docs : actualizar guia de instalacion**
- Relacionar ramas a issues
